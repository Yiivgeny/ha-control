# Brand asset provenance

Both original PNGs were generated with the built-in imagegen tool and copied unchanged into the project, preserving transparency. The integration and app use distinct variants of the same house/brackets motif. `logo.png` reuses each variant's icon mark. No Home Assistant official brand artwork was copied.

## Integration prompt

Use case: logo-brand. Create an original polished flat logo icon for the open-source Home Assistant integration HA Control. A bold geometric house outline cleverly fused with a pair of clean code brackets and one small central connected node, communicating broad smart-home control. Restrained electric blue and cyan palette, crisp simple silhouette readable at 32 pixels, balanced generous transparent padding, genuinely transparent PNG background. Square 1024x1024. One single centered mark, no text, no mockup, no shadows, no watermark. Do not copy the official Home Assistant logo. This is the integration variant of a matching two-icon family.

## Companion app prompt

Use case: logo-brand. Create an original polished flat logo icon for the open-source HA Control MCP companion server app. A bold geometric house outline cleverly fused with clean code brackets; inside, two small stacked rounded server bars with one connection dot each, communicating the smart-home server. Restrained turquoise and teal palette, crisp simple silhouette readable at 32 pixels, balanced generous transparent padding, genuinely transparent PNG background. Square 1024x1024. One single centered mark, no text, no mockup, no shadows, no watermark. Do not copy the official Home Assistant logo. This is the server variant of a matching two-icon family.
